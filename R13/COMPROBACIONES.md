# Comprobaciones de R13

Abre https://atajoia.github.io/R13/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 5 filas con 5 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- Búsqueda local de palabras: no usa IA ni evalúa legalidad, abusividad, validez o conveniencia de firmar.
- Las citas son fragmentos exactos de tu entrada. Revisa el contexto y los anexos; las coincidencias pueden repetirse o ser irrelevantes.
- 5 coincidencias para revisar. No constituye una auditoría completa del contrato.
- No se calculan multas ni se citan leyes. Para un contrato real consulta a un abogado con el documento completo.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
