# Comprobaciones de R06

Abre https://atajoia.github.io/R06/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 4 filas con 5 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- Redacción con plantillas por reglas; no conecta con Google ni envía respuestas. Personaliza cada borrador antes de usarlo.
- Nunca concede descuentos, reembolsos, cambios ya realizados o investigaciones concluidas. No pide modificar la reseña ni ofrece incentivos.
- No se añadió un contacto: no se inventa teléfono, correo o enlace.
- Casos de cobro, salud, trato o amenazas se escalan; la calificación no sustituye una investigación. No hay traducción automática: elige el idioma del borrador.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
