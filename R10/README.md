# Guía de Estructura de Texto para Diagramas de Flujo Automáticos

Recurso gratuito de **Atajo IA** que acompaña al reel **R10 · De Nota de Texto a Diagrama de Flujo en Segundos** (palabra clave: PROCESO).

> **Material educativo.** Úsalo como borrador: revisa cada resultado antes de usarlo o compartirlo. No sustituye la revisión de una persona ni la asesoría profesional.

## Qué es

Transforma apuntes sueltos o procedimientos en bloque de texto en una tabla estructurada y código visual para generar diagramas de flujo sin dibujar a mano. Está diseñado para profesionistas, encargados de operaciones y dueños de negocio que documentan procesos internos. No reemplaza el criterio operativo ni valida reglas de negocio: entrega un borrador que siempre debes revisar antes de oficializar.

## Qué incluye

- `README.md`: Guía: qué es, cómo usarlo paso a paso, requisitos y privacidad.
- `PROMPT_MAESTRO.md`: Prompts listos para copiar en tu asistente de IA.
- `plantilla_proceso.csv`: Plantilla con las columnas de la demo (PASO, ACCIÓN DETECTADA, ÁREA, NODO); las filas EJEMPLO son ilustrativas: bórralas y pega tus datos.

## Requisitos

- Tus apuntes o descripción del procedimiento en texto plano
- Acceso a un asistente de IA aprobado por tu organización
- Excel o Google Sheets para abrir la plantilla CSV
- Un visor o editor compatible con código Mermaid o tablas de procesos para exportar tu PDF

## Cómo usarlo paso a paso

1. Reúne tus notas del procedimiento en un documento de texto y reemplaza nombres reales, montos sensibles o datos privados por etiquetas genéricas.
2. Abre el archivo PROMPT_MAESTRO.md incluido en esta descarga, copia el prompt principal y pégalo en tu asistente de IA.
3. Inserta tus notas limpias en el espacio [TEXTO_DEL_PROCESO] y ejecuta la instrucción para obtener la tabla estructurada.
4. Copia las filas generadas por el asistente y pégalas en la plantilla CSV usando Excel o Google Sheets para revisar el orden de los pasos.
5. Compara cada fila contra tus apuntes originales para confirmar que ninguna condición, área responsable o ruta de rechazo se haya omitido o malinterpretado.
6. Usa los prompts complementarios para generar el código de diagrama en carriles y llévalo a tu herramienta de diagramación para exportar el archivo PDF final.
