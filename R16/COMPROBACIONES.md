# Comprobaciones de R16

Abre https://atajoia.github.io/R16/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 3 filas con 6 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- La extracción es por reglas: no confirma compromisos ni comprende todo un historial.
- La fecha de un mensaje no se toma como fecha límite. Fechas relativas, múltiples o inválidas quedan Por confirmar.
- Conserva la evidencia y revisa cambios/contradicciones antes de dar seguimiento. No se envía ningún mensaje.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
