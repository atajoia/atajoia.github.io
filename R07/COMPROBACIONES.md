# Comprobaciones de R07

Abre https://atajoia.github.io/R07/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 15 filas con 5 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- 14 bloque(s) de notas distribuidos en catorce láminas de contenido más portada.
- Conserva el texto y las cifras que proporcionaste; no inventa conclusiones, porcentajes, causas, fechas o responsables.
- Si faltan notas, deja láminas marcadas para completar. Revisa legibilidad y datos antes de presentar. Puedes descargar el guion Markdown; no se crea un PPTX ni se opera un editor externo.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
