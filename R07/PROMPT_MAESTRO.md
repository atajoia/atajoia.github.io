# Prompt maestro · Presentación: convertir notas en una historia

Recurso de Atajo IA para el reel R07. Copia cada bloque en el asistente de IA que tu organización permita usar, reemplaza los [MARCADORES] y revisa el resultado antes de usarlo.

## 1. Prompt principal

Diseñar un primer guion de diapositivas que conserve las fuentes y no invente cifras.

```text
Propón una presentación de [NÚMERO] diapositivas para [AUDIENCIA]. Objetivo: [DECISIÓN O APRENDIZAJE]. Usa estas notas como única fuente: [NOTAS ANONIMIZADAS]. Para cada diapositiva devuelve título, idea principal, evidencia disponible y visual sugerido. Marca como PENDIENTE cualquier cifra o dato que falte; no inventes estadísticas ni citas. Termina con una lista de comprobación antes de presentar.
```

## 2. Auditoría de cifras y fuentes contra el original

Cuándo usarlo: Úsalo justo después de generar el guion para detectar datos inventados o exageraciones antes de armar las diapositivas.

```text
Compara este borrador de diapositivas con mis notas originales. Borrador: [PEGAR GUION GENERADO]. Notas originales: [PEGAR NOTAS ANONIMIZADAS]. Señala en una tabla cualquier cifra, porcentaje, fecha o afirmación del borrador que no aparezca textualmente en las notas originales. No corrijas por tu cuenta: solo enlista las discrepancias y marca qué láminas requieren revisión manual.
```

## 3. Convertir apuntes sueltos o transcripción de voz

Cuándo usarlo: Úsalo cuando solo tengas ideas desordenadas de una reunión o la transcripción de una nota de voz en lugar de un documento formal.

```text
Tengo estos apuntes desordenados sobre [TEMA DE LA REUNIÓN]: [PEGAR APUNTES O TRANSCRIPCIÓN ANONIMIZADA]. Agrupa las ideas por temas lógicos, elimina repeticiones y muletillas, y propón un índice de [NÚMERO] secciones para una presentación dirigida a [AUDIENCIA]. Si un punto está incompleto o es confuso, márcalo como [ACLARAR CON EL EQUIPO] sin inventar contexto.
```

## 4. Formato de esquema para importar a diapositivas

Cuándo usarlo: Úsalo cuando ya validaste el contenido y quieres pasarlo rápido a PowerPoint o a tu herramienta de diseño mediante un esquema limpio.

```text
Convierte este guion validado en un esquema de texto jerárquico listo para copiar: [PEGAR GUION VALIDADO]. Usa el nivel 1 para el título de cada lámina y el nivel 2 para un máximo de 3 viñetas cortas por diapositiva (máximo 12 palabras por viñeta). Al final de cada lámina, escribe entre corchetes la instrucción para mí sobre qué tabla, cifra o gráfica debo insertar manualmente.
```

## Antes de usar el resultado

- Verifica cifras, fuentes, permisos de imágenes y afirmaciones.
- Adapta el contenido a la audiencia y al tiempo disponible.
- Elimina información confidencial antes de usar herramientas externas.
