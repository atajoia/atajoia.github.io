# Comprobaciones de R03

Abre https://atajoia.github.io/R03/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 3 filas con 4 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- Convierte líneas estructuradas en acuerdos. No deduce responsables, años, horas ni fechas de expresiones como mañana.
- El año opcional solo se aplica si lo indicas expresamente. Las asignaciones no se marcan terminadas.
- 1 fila(s) necesitan confirmación.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
