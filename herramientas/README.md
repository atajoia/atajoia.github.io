# Mini herramientas de Atajo IA

Uso gratuito en GitHub Pages. Cada aplicación funciona en el navegador con reglas,
cálculos y plantillas locales, sin cuenta, claves, llamadas a modelos ni suscripciones.
Los datos de trabajo no se envían a un servidor ni se guardan automáticamente.

Abre `../R01/app/` (hasta R20) para usar una herramienta. En cada carpeta también hay
un archivo `atajo-rXX.html` autónomo: descárgalo y ábrelo en un navegador. No necesita
instalación ni servidor local. El código fuente está en esta carpeta y se puede copiar.
Los originales seleccionados en el organizador no se modifican; se descarga un ZIP
con copias y los nombres revisados.

Las guías y datos de práctica están en las carpetas R01–R20. Las funciones no son una
IA remota: las tareas semánticas requieren revisar los borradores y completar datos
que no estén explícitos. No hay reconocimiento de PDF escaneado, audio ni envío de mensajes.
