# Comprobaciones de R15

Abre https://atajoia.github.io/R15/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 5 filas con 3 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- Los nombres nuevos son una propuesta. Los originales no se renombran ni se sobrescriben.
- Se preservan extensiones y se comparan colisiones sin distinguir mayúsculas, como precaución para Windows.
- Las filas con Revisar conservan el nombre original. No inventamos fechas a partir de la modificación del archivo.
- Antes de aplicar o descargar una copia renombrada, compara nombre, contenido y número de archivos.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
