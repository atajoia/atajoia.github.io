# Comprobaciones de R14

Abre https://atajoia.github.io/R14/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 7 filas con 8 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- Se conservan 7 filas y todas las columnas originales. Las propuestas no sobrescriben los datos.
- Los IDs se comparan después de quitar espacios externos, respetando mayúsculas. Nombres parecidos no prueban identidad.
- No se ha sumado, sustituido ni consolidado ningún saldo. La coincidencia de reglas no certifica que los datos sean correctos.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
