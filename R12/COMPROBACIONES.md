# Comprobaciones de R12

Abre https://atajoia.github.io/R12/app/, carga DATOS_PRACTICA.txt y las opciones de OPCIONES_EJEMPLO.txt. El procesador actual produce 5 filas con 4 columnas. Compara la tabla editable con RESULTADO_ESPERADO.csv antes de descargar o usarla.

## Límites y notas del procesador

- Manual armado en tu navegador con las acciones que escribiste; no controla otros programas.
- Puedes descargar el texto o una versión HTML imprimible desde la interfaz. Esto no publica ni comparte el documento.
- Una comprobación vacía queda Por confirmar. Ningún manual se marca probado automáticamente.

## Descargas

CSV conserva la tabla revisada; Markdown/HTML conservan el documento que ofrece la app. Descargar una propuesta no significa enviarla, renombrar tus originales ni ejecutar acciones en otros servicios. La aplicación funciona con reglas locales, sin API de pago ni registro.
