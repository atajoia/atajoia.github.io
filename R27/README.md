# Claude: cobra cambios fuera de alcance

Recurso gratuito de Atajo IA · R27 · ALCANCE

## Herramienta y preparación

Claude.ai en navegador web (cuenta gratuita)

- Cuenta gratuita de Claude.ai y mensaje ficticio del cliente.

Usa DATOS_PRACTICA.txt como entrada. Son datos ficticios, no una transcripción real.

## Pasos del video

1. **Abre el chat:** Carga el mensaje de práctica en un chat nuevo de Claude.ai.
2. **Envía el prompt:** Pega el prompt completo y pulsa Enviar.
3. **Revisa y guarda:** Comprueba 3 párrafos, $3,500.00 y 20 de mayo; copia a Respuesta_Alcance.txt.

## Prompt completo

```text
Cliente: «¿Sumamos 2 pantallas antes del viernes?». Acuerdo: 3 pantallas base. Redacta 3 párrafos sin disculpas: valida la idea; recuerda el acuerdo; ofrece mantener el plan actual sin costo extra o sumar 2 pantallas por $3,500.00 para el 20 de mayo.
```

## Comprobación

Tres párrafos sin disculpas; ambas opciones, monto y fecha correctos.

RESULTADO_ESPERADO.csv es una referencia ilustrativa; compara cada dato con la entrada. La respuesta de una IA puede variar y requiere revisión.
